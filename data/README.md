# Data

Пациентские данные не хранятся в Git.

Локально рекомендуется использовать:

```text
data/
├── raw/
│   └── <case>/
├── processed/
└── synthetic/
```

`data/raw/` исключён через `.gitignore`.

Для воспроизводимых unit/integration tests в репозиторий допускаются только синтетические или полностью обезличенные тестовые наборы без персональных идентификаторов.
