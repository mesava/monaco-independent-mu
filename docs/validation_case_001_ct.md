# Проверка CT-контура на первом validation case

Этот документ содержит только технические характеристики набора и не содержит
пациентских идентификаторов или DICOM.

## Проверенные свойства CT

- 140 CT-срезов;
- матрица каждого среза: 512 × 512;
- PixelSpacing: 0.935547 × 0.935547 мм;
- spacing вдоль нормали к срезу: 2.5 мм;
- ImageOrientationPatient: axial, без наклона;
- PatientPosition: HFS;
- KVP: 120;
- RescaleSlope: 1;
- RescaleIntercept: −1024;
- одна CT SeriesInstanceUID;
- один FrameOfReferenceUID;
- диапазон координаты вдоль нормали: −150.0 … +197.5 мм.

## Первичный контроль HU

По полной CT-матрице, включая область вне внешнего контура пациента:

- минимальный HU: −3024;
- максимальный HU: +3071;
- вокселей выше верхней точки CT calibration (+2009 HU): 1284.

Эти 1284 вокселя пока **не интерпретируются как ткань/металл**. Следующий этап
обязан применить внешний контур пациента и отдельно классифицировать значения
внутри и вне Patient/External ROI.

## Следующий контроль

1. Построить BODY/Patient mask из RTSTRUCT.
2. Рассчитать статистику HU только внутри пациента.
3. HU → RED по DRT120kV.
4. RED → mass density после окончательной верификации формулы.
5. Patient material LUT → material/material-mixture map.
